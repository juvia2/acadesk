# 아카데스크 기획안 v2

작성 2026-11-01 · 이전 기획: `docs/planning/기획안.md` (수납·출결 안내 자동화 중심)

> **v2에서 바뀐 점:** 담당자만 쓰던 안내 자동화 도구에서 **학원 관리자·교사·학생·학부모 네 역할이 각자 로그인해 쓰는 학원 플랫폼**으로 바뀝니다. 핵심은 강의별 QR 출결, 학부모 리포트, 긴급 문자, 학부모 익명 커뮤니티입니다.

## 1. 한 줄 소개

학원의 **강의별 출결을 QR로 정확하게 기록**하고, 학부모는 그 기록으로 자녀의 학원 생활을 **리포트로 확인**하며, 같은 학원 학부모끼리 **익명으로 정보를 나누는** 학원 플랫폼.

## 2. 해결할 문제

| 누구 | 지금의 불편 | 아카데스크에서 |
|---|---|---|
| 학원 관리자 | 출결·공지·상담이 종이, 메신저, 개인 휴대전화에 흩어짐. 문자 비용 부담 | 한 화면에서 관리. 일반 공지는 앱으로, 문자는 긴급할 때만 |
| 교사 | 강의마다 출석 부르고 장부에 옮겨 적음 | 강의 시작 때 QR을 띄우면 출결이 자동 기록 |
| 학생 | 선생님께 따로 질문하기 어려움 | 앱에서 QR 출석, 공지 확인, 선생님께 질문 |
| 학부모 | 아이가 학원에 실제로 갔는지, 어떻게 지내는지 알기 어려움. 다른 학부모와 정보 교류가 어려움 | 강의별 출결·과제·공지를 리포트로 확인. 같은 학원 학부모 익명 커뮤니티 |

## 3. 사용자와 역할

| 역할 | 누구 | 가입 방식 |
|---|---|---|
| 학원 관리자 | 원장·실장 | 학원 등록과 함께 가입 (학원의 첫 계정) |
| 교사 | 강사 | 관리자가 보낸 초대 링크로 가입 |
| 학생 | 수강생 | 관리자가 발급한 **학생 초대 코드**로 가입 → 학생 명부와 연결 |
| 학부모 | 보호자 | 관리자가 발급한 **학부모 초대 코드**로 가입 → 자녀와 연결 |

**가입 원칙**
- 아무나 "이 학원 학부모"로 가입할 수 없게 합니다. 초대 코드는 학생별·보호자별로 발급하고, 한 번 쓰면 만료됩니다.
  - 커뮤니티가 "이 학원 학부모만 있는 곳"이라는 신뢰는 이 인증에서 나옵니다. 블라인드가 회사 이메일로 재직을 인증하는 것과 같은 역할입니다.
- 학부모 한 명이 자녀 여러 명과 연결될 수 있습니다(형제). 자녀마다 코드를 입력하면 같은 계정에 추가됩니다.
- 로그인하면 **역할에 따라 다른 화면**으로 들어갑니다. 한 사람이 두 역할이면(교사이면서 학부모) 역할 전환 메뉴를 둡니다.
- 퇴원하면 학생 계정은 읽기 전용이 되고, 학부모의 커뮤니티 이용은 유예 기간(예: 30일) 뒤 종료됩니다.

## 4. 역할별 화면

### 학원 관리자
- 대시보드: 오늘 강의, 출석률, 결석자, 답변 안 된 질문, 커뮤니티 신고 건수
- 학생·학부모·교사 관리, 초대 코드 발급
- 강의 관리: 강의 개설, 시간표, 담당 교사, 수강생 배정
- 출결 현황과 정정
- 공지사항 작성 (학원 전체 / 강의별)
- 긴급 문자 발송
- 수납 기록 (청구·납부 등록) → 학부모 리포트에 표시
- 운영 설정: 지각 기준 시간, QR 유효 시간, 커뮤니티 운영 방식

### 교사
- 오늘 내 강의 목록
- **강의 시작 → QR 화면 띄우기**, 실시간 출석 현황 (출석 n명 / 미출석 명단)
- 출결 수동 처리 (휴대전화가 없는 학생, 오류 정정)
- 질의응답: 학생 질문 답변, 학부모 상담 답변
- 강의 공지, 과제 등록·제출 체크
- 긴급 문자 발송 (내 강의 학생의 학부모에게만)

### 학생
- **QR 스캔 (카메라 켜기)** → 출석 완료 화면
- 공지사항
- 질의응답: 선생님께 질문·상담
- 내 시간표, 내 출결 (확장)

### 학부모
- **자녀 리포트** (아래 6장)
- 공지사항
- 상담: 선생님께 문의
- **학부모 커뮤니티** (아래 8장)
- 알림: 출석·결석 알림(앱 푸시), 긴급 문자 수신
- 자녀가 둘 이상이면 상단에서 자녀 전환

## 5. 강의별 QR 출결

출결 단위는 **날짜가 아니라 강의 회차**입니다. 같은 날 수학·영어를 들으면 출결도 두 건입니다.

**흐름**
1. 시간표에 따라 강의 회차가 자동으로 만들어집니다 (예: 11/3 월 16:00 중2 수학).
2. 교사가 강의 화면에서 "출석 시작"을 누르면 교실 화면(태블릿·노트북·TV)에 QR이 뜹니다.
3. 학생이 앱에서 QR을 찍으면 서버가 확인하고 출석으로 기록합니다. 찍은 시각이 남습니다.
4. 시작 시각 + 지각 기준(예: 10분)이 지나 찍으면 지각입니다.
5. 강의가 끝날 때까지 찍지 않은 학생은 결석으로 처리되고, 학부모에게 앱 푸시가 갑니다.
6. 교사는 언제든 수동으로 정정할 수 있고, 정정 기록이 남습니다.

**대리 출석 방지**

"매일 다른 QR"만으로는 QR을 사진으로 찍어 친구에게 보내는 대리 출석을 막지 못합니다. 그래서 아래를 같이 적용합니다.

| 장치 | 내용 |
|---|---|
| 짧게 바뀌는 QR | QR 안의 토큰이 30초마다 바뀝니다. 사진을 찍어 보내도 곧 무효가 됩니다 |
| 강의 시간 제한 | 그 강의 회차의 출석 가능 시간(시작 15분 전 ~ 종료)에만 받습니다 |
| 수강생 확인 | 그 강의 수강생이 아니면 거부합니다 |
| 1인 1회 | 같은 회차에 두 번 찍으면 첫 기록만 인정합니다 |
| 기기 기록 | 학생 계정이 쓰는 기기를 기록해, 한 기기로 여러 학생이 찍으면 교사에게 표시합니다 (확장) |

- 웹(PWA)으로 시작합니다. 휴대전화 브라우저에서도 카메라로 QR을 읽을 수 있습니다(HTTPS 필요). 앱스토어 출시는 확장 단계입니다.
- 학생이 휴대전화가 없거나 배터리가 없을 때는 교사가 수동으로 출석 처리합니다.

## 6. 학부모 리포트

**MVP: 이미 모이는 기록으로 만드는 항목**

| 항목 | 내용 |
|---|---|
| 강의별 출결 | 기간 출석률, 강의별 출석·지각·결석, 달력 보기, 결석 사유, 보강 여부 |
| 등원 확인 | QR 찍은 시각 = 실제 교실 도착 시각. "오늘 중2 수학 16:02 출석" |
| 시간표 | 자녀 강의 일정, 휴강·보강 |
| 과제 | 강의별 제출률, 미제출 목록 |
| 공지 | 자녀 강의 관련 공지 |
| 수납 | 이번 달 청구, 납부 여부, 남은 금액. 형제는 합산 |
| 긴급 알림 이력 | 학원이 보낸 긴급 문자 목록 |

**확장: 교사 입력이 필요한 항목**

| 항목 | 내용 |
|---|---|
| 수업 진도 | 강의별 오늘 배운 단원 (수업일지) |
| 테스트 성적 | 점수 추이. 반 평균은 평균값만, 다른 학생 점수는 노출 안 함 |
| 선생님 코멘트 | 월 1회 수업 태도·참여 한 줄 평 |
| 월간 요약 | 위 항목 요약. AI가 초안을 쓰고 교사가 확인한 뒤 공개 |

- 기간: 주간 / 월간
- **학생–교사 질의응답은 학부모에게 기본 비공개**입니다. 학생이 부모에게 알리기 싫은 질문을 할 수 있기 때문입니다. 학부모–교사 상담은 학부모가 볼 수 있습니다.

## 7. 공지사항과 질의응답

**공지사항**
- 작성: 관리자(학원 전체 또는 강의별), 교사(자기 강의)
- 대상: 학생 / 학부모 / 둘 다
- 상단 고정, 첨부 파일, 읽음 확인 (누가 아직 안 읽었는지 관리자에게 표시)
- 새 공지는 앱 푸시로 알림. 문자는 쓰지 않음

**질의응답 (상담)**
- 학생 → 선생님, 학부모 → 선생님(또는 학원)
- 1:1 대화 형식. 질문 하나를 스레드로 두고 답변이 달리면 "답변 완료"
- 공개 Q&A 옵션: 학생이 원하면 질문을 같은 강의 학생에게 익명 공개 (같은 질문 반복 감소, 확장)
- 관리자는 답변이 오래 밀린 질문을 대시보드에서 봄

## 8. 학부모 익명 커뮤니티

같은 학원에 다니는 **인증된 학부모만** 참여하는 게시판입니다. 블라인드처럼 소속은 인증하되 글은 익명으로 쓸 수 있고, 당근처럼 같은 울타리(학원) 안에서 교재 나눔 같은 생활 정보를 나눕니다.

### 8-1. 공개 범위와 작성자 표시

글마다 두 가지를 고릅니다.

| 선택 | 옵션 | 설명 |
|---|---|---|
| 작성자 표시 | **익명** | "익명" 또는 "중2 학부모"처럼 표시. 같은 글 안에서는 댓글 작성자를 "익명1, 익명2"로 구분 |
| | **공개** | 본인이 정한 닉네임으로 표시 |
| 공개 범위 | **학원 전체** | 이 학원의 모든 인증 학부모 |
| | **같은 학년·강의만** | 자녀가 같은 학년이나 같은 강의인 학부모만 |

- "중2 학부모" 같은 소속 표시는 그 그룹의 학부모가 **5명 이상일 때만** 보여줍니다. 소수 그룹에서는 표시만으로 누군지 짐작되기 때문입니다.
- 익명 글도 서버는 실제 작성자를 알고 있습니다. 신고 처리와 법적 요청에만 쓰고, 학원에도 보여주지 않습니다.

### 8-2. 학원은 커뮤니티를 볼 수 있나

블라인드가 신뢰받는 이유는 회사가 글을 볼 수 없기 때문입니다. 학원 관리자가 다 볼 수 있으면 학부모가 솔직하게 쓰지 않습니다.

| 방식 | 장점 | 단점 |
|---|---|---|
| **A. 학원 열람 불가 (추천)** | 솔직한 정보 교류, 커뮤니티 활성화 | 학원이 운영 책임을 지기 어려움 → 플랫폼(우리)이 신고 처리 |
| B. 학원 열람 가능 | 학원이 직접 관리 | 학부모가 쓰지 않음. 학원 입장에서는 감시 도구로 보일 수 있음 |

- 추천안 A에서도 학원은 **신고 건수**와 학부모가 **"학원에 전달"을 선택한 글**(건의사항)만 받습니다.
- 학원이 이 기능을 켜고 끌 수는 있게 합니다. 학원 영업에 불리한 글이 걱정되는 학원도 있기 때문입니다. 이 부분은 영업 전략과 같이 정합니다.

### 8-3. 게시판

| 게시판 | 내용 |
|---|---|
| 자유 | 일상, 학원 생활 이야기 |
| 질문 | "중2 수학 숙제 양 어떤가요?" 같은 질문 |
| 정보 공유 | 시험 일정, 교재, 학교별 정보 |
| 나눔·거래 | 교재·문제집·교복 나눔과 중고 거래. **결제는 앱에서 하지 않음** (당사자끼리) |
| 학원에 건의 | 익명으로 학원에 의견 전달. 이 글만 학원이 볼 수 있음 |

- 공통 기능: 댓글, 공감, 북마크, 검색, 신고, 사용자 차단, 내 글 알림

### 8-4. 안전장치

학부모 커뮤니티는 다른 집 아이·교사 이야기가 오가므로 운영 위험이 큽니다.

| 위험 | 장치 |
|---|---|
| 아이·교사 실명, 연락처 노출 | 글 저장 전에 전화번호·실명 패턴 자동 가림, 작성 시 경고 |
| 비방·명예훼손 | 신고 3건이면 자동 임시 블라인드 → 운영자 검토. 정보통신망법의 임시조치 절차에 맞춰 처리 |
| 욕설·광고 | 금칙어 필터, 다른 학원·과외 홍보 차단 |
| 익명 악용 | 제재는 익명 뒤의 실제 계정에 적용 (글쓰기 정지, 강제 탈퇴) |
| 소수 그룹 신원 노출 | 5명 미만 그룹은 소속 표시 숨김 |
| 퇴원 후 접근 | 퇴원 30일 뒤 커뮤니티 접근 종료. 쓴 글은 익명으로 남거나 본인이 삭제 |

- 가입 시 커뮤니티 이용 규칙에 동의해야 글을 쓸 수 있습니다.
- AI 보조(확장): 신고된 글이나 위험 표현이 있는 글을 운영자 검토 대기열 위쪽으로 올림. 삭제는 사람이 결정합니다.

## 9. 긴급 문자

일반 공지·출결 알림은 앱 푸시로 보내고, **문자는 정말 긴급할 때만** 씁니다. 문자는 비용이 들고, 자주 보내면 학부모가 무시하게 되기 때문입니다.

- 보내는 사람: 관리자(전체), 교사(자기 강의 학생의 학부모만)
- 예: 수업 중 학생 부상·건강 이상, 무단결석 후 연락 두절, 재난·휴원 긴급 공지
- 보낼 때:
  1. 사유 유형을 고르고 (안전, 건강, 휴원, 기타)
  2. 수신자 수와 문구를 확인하는 화면을 거쳐 발송
  3. 발송 기록(누가, 언제, 누구에게, 왜)이 감사 로그에 남음
- 앱 푸시를 같이 보내고, 앱을 안 쓰는 학부모에게는 문자만 갑니다.
- 남용 방지: 교사가 학원 전체에 보내는 것은 불가. 하루 발송 건수를 학원 설정으로 제한.
- 외국인 학부모는 수신 언어로 번역된 문구를 같이 보냅니다 (기존 다국어 기획 유지).

## 11. 출시 순서 (안)

| 단계 | 범위 |
|---|---|
| **MVP** | 4역할 가입·초대 코드, 역할별 화면, 강의·시간표, **QR 강의별 출결**, 공지, 질의응답, 학부모 리포트(출결·시간표·공지), 긴급 문자, 형제 연동 |
| **2단계** | **학부모 커뮤니티**(신고·블라인드 포함), 과제, 수납 기록과 리포트 표시, 앱 푸시 고도화 |
| **3단계** | 수업 진도·성적·코멘트, 월간 요약(AI), 커뮤니티 AI 검토 보조, 다국어 번역, 앱스토어 출시 |

커뮤니티를 MVP가 아닌 2단계에 둔 이유: 신고·임시조치 운영 체계 없이 열면 위험하고, 학부모 가입자가 어느 정도 모여야 커뮤니티가 돌아갑니다. 학부모 리포트로 먼저 가입을 모은 뒤 여는 순서를 추천합니다.

## 13. 개인정보·법

- 학생 대부분이 미성년자입니다. **만 14세 미만 학생 가입은 법정대리인(학부모) 동의**가 필요합니다. 학생 초대 코드를 학부모 계정에서 승인하는 흐름으로 처리합니다.
- QR 출결 시각은 위치 정보가 아닌 출결 기록으로만 씁니다. 위치(GPS) 수집은 하지 않습니다.
- 커뮤니티는 정보통신망법상 게시판 운영자 의무(신고 처리, 임시조치)를 따릅니다. 운영 주체(학원 / 우리)를 이용약관에 명시합니다.
- 나눔·거래 게시판에서 결제를 받지 않습니다. 결제를 붙이면 통신판매중개 의무가 생깁니다.
- 긴급 문자 수신은 학원 등록 시 학부모 동의를 받습니다.
